## What We Have Done

### Day 1:

- **FastAPI Application Setup**: Initialized a FastAPI app configured with a `/health` GET endpoint.
- **Pydantic Data Modeling (`Document`)**:
  - `filename`: Required string (1-255 characters).
  - `file_type`: Validated against allowed formats (`pdf`, `txt`, `md`, `docx`, `csv`, `json`).
  - `size_bytes`: Strictly positive integer with a 50 MB limit.
  - `description`: Optional field with a maximum length of 500 characters.
- **Document Ingestion Endpoint**: Created `POST /documents` with automatic request body validation.
- **Automated Test Suite**: Built automated tests in `tests/test_api.py` using `pytest` and FastAPI's `TestClient` covering:
  - Health check endpoint
  - Valid document submission
  - Invalid document attributes (file size limits, unsupported extensions, empty filenames)
  - Missing required fields
